# Подключение приветствия с iPhone

Эти действия добавляют только ответ на /start. Визитка и Menu Button уже работают и не требуют перенастройки.

## 1. Создайте Worker

1. Откройте https://dash.cloudflare.com/ в Safari. Войдите или создайте аккаунт.
2. Если редактор не виден, выберите в меню Safari **«Запросить настольный веб-сайт»**.
3. Откройте **Workers & Pages** (иногда внутри **Compute & AI**).
4. Нажмите **Create application → Create Worker / Start with Hello World**.
5. Назовите Worker, например, `nikolay-transport-start`, и нажмите **Deploy**. Используйте Workers Free.
6. Откройте **Edit code**.
7. В другой вкладке откройте https://github.com/anufrii2020-sudo/Nikolay-Card/blob/main/telegram-bot/worker.js . Нажмите **Raw / View raw**, выделите весь текст и скопируйте.
8. Полностью замените демонстрационный код Worker этим worker.js. Не вставляйте его в index.html визитки.
9. Нажмите **Save and Deploy / Deploy**.
10. В **Settings → Observability / Logs** отключите **Workers Logs**. Не подключайте Logpush и журналирование исходящих запросов.

Теперь Worker существует, но приветствие бота ещё не подключено.

## 2. Добавьте секреты

1. Нажмите **Visit** у Worker и допишите `/setup` к его публичному workers.dev-адресу. Используйте публичный адрес, не Preview редактора.
2. Раскройте **«Сгенерировать два секрета на этом устройстве»** и нажмите кнопку генерации.
3. Сохраните оба значения в своём менеджере паролей. Они созданы локально; не отправляйте их в чат или URL.
4. В Telegram откройте официальный **@BotFather → /mybots → @NikolayTransportBot → API Token**. Скопируйте токен. Не меняйте Menu Button, Mini App и /card.
5. В Cloudflare откройте Worker → **Settings → Variables and Secrets → Add**.
6. Добавьте три записи с типом **Secret**, точно соблюдая имена:

   - `BOT_TOKEN` — токен из BotFather.
   - `WEBHOOK_SECRET` — первое сгенерированное значение.
   - `SETUP_KEY` — второе сгенерированное значение.

7. Нажмите **Save / Deploy**, если Cloudflare предлагает применить изменения.

Токен вводится только в защищённое поле Cloudflare. Его не нужно присылать мне, добавлять в GitHub Secrets, вставлять в код или ссылку api.telegram.org.

## 3. Подключите webhook

1. Снова откройте публичный адрес Worker с `/setup`.
2. Введите свой SETUP_KEY в поле пароля.
3. Нажмите **«Проверить подключение»**. При правильных секретах появятся `ok: true` и `bot: NikolayTransportBot`.
4. Если `another_webhook_exists: true`, у бота уже есть другой обработчик. Подключение заменит его: сначала убедитесь, что прежняя интеграция больше не нужна. Это не относится к Menu Button, которая не меняется.
5. Нажмите **«Подключить webhook»**.
6. Дождитесь `ok: true`, `webhook_connected_here: true` и текста **«Webhook подключён»**.

Регистрация выполняется Cloudflare с secret_token. Команды с токеном в адресной строке не нужны. Webhook — адрес Worker с `/webhook`; GitHub Pages и ссылка t.me/.../card для приёма обновлений не подходят.

## 4. Проверьте реальный ответ

1. Откройте @NikolayTransportBot в Telegram.
2. Нажмите **«Запустить»** в чате либо отправьте `/start` вручную.
3. Убедитесь, что пришёл текст:

   Здравствуйте!

   Я Николай. Более 15 лет работаю в грузоперевозках.

   Помогаю перевозчикам с топливом, грузовыми шинами и загрузками.

   Откройте визитку, выберите направление и напишите мне напрямую.

4. Под сообщением должна быть кнопка **«Открыть визитку»**. Нажмите её: должна открыться прежняя визитка через https://t.me/NikolayTransportBot/card .
5. Проверьте прежнюю **Menu Button**: она должна открывать то же Mini App.
6. Отправьте /start ещё раз: он снова получает приветствие. Обычное сообщение без /start ответа не получает — это ожидаемо.

Только после этих действий реальный запуск считается проверенным.

## Если возникла ошибка

- `forbidden` — выполните [безопасную диагностику SETUP_KEY](AUTH-DIAGNOSTICS.md): новая страница показывает точную категорию отказа и версию Production без раскрытия ключа. Сначала используйте «Проверить ключ без Telegram»; BOT_TOKEN и WEBHOOK_SECRET менять не нужно.
- `secrets_not_configured` — проверьте BOT_TOKEN и WEBHOOK_SECRET, тип Secret, отсутствие пробелов, затем Deploy.
- `wrong_bot` — токен принадлежит другому боту; нужен @NikolayTransportBot.
- `telegram_unavailable` — проверьте актуальность BOT_TOKEN и повторите позже. Подробности намеренно не выводятся, чтобы не раскрыть токен.
- `webhook_connected_here: false` после подключения — используйте публичный workers.dev-адрес, повторите подключение, проверьте, не перенастраивает ли webhook другая интеграция.
- Ответа нет — проверьте /setup и отправьте /start именно в личный чат правильного бота. Не включайте журналирование запросов с секретами и не присылайте скриншоты значений токена.

Если мобильный редактор неудобен, можно импортировать этот GitHub-репозиторий через **Workers & Pages → Create application → Import a repository**. Корневая папка проекта — `telegram-bot`, команда развёртывания — `npx wrangler deploy`, отдельная сборка не требуется. Секреты добавляются только в Cloudflare.
