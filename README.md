# Николай / Транспорт

Статическая мобильная визитка на HTML/CSS с небольшим JavaScript для ссылок. Без сборки, библиотек, сервера, форм, аналитики и автоматической отправки сообщений.

## Файлы

- `index.html` — тексты, карточки и готовые контактные href.
- `style.css` — оформление. Мобильные карточки сохранили высоту 66 px.
- `script.js` — функция `telegramChatLink(message)` и обновление ссылок по атрибутам `data-telegram-message`.
- `truck.jpg`, `favicon.svg`, `.nojekyll` — прежние hero и служебные файлы.
- `assets/icon_fuel_cutout.webp`, `assets/icon_truck_tire_cutout.webp`, `assets/icon_cargo_cutout.webp` — обработанные версии предоставленных предметных PNG: удалены квадратные рамки и фон, сохранены реалистичные материалы и усилена читаемость освещения. Прозрачность хранится в файлах, CSS предметы не вырезает. Целые изображения выводятся через object-fit: contain в контейнерах 50×50 px.
- `assets/fuel.webp`, `assets/tires.webp`, `assets/cargo.webp` — прежние затемнённые тематические фотографии справа.

Исходные PNG с рамками сохранены в рабочем проекте как исходники; новая страница их не подключает. Страница не использует скриншот эталона как фон.

## Запуск и изменение

Откройте index.html или выполните `python3 -m http.server 8000` и перейдите на http://localhost:8000. Все тексты находятся в HTML; оформление — в CSS. Сообщения для четырёх ссылок записаны в `data-telegram-message` и уже закодированы в соответствующих href. При редактировании сообщений обновляйте и атрибут, и статический href; JavaScript дополнительно синхронизирует их после загрузки.

Функция возвращает прямую ссылку на конкретного пользователя с percent-encoded черновиком:

```js
function telegramChatLink(message) {
  return `https://t.me/Nikolai_Makes_Sense?text=${encodeURIComponent(message)}`;
}
```

Ссылки существуют в HTML и работают без JavaScript. Верхняя иконка Telegram ведёт к тому же username без подготовленного текста. Сайт не отправляет сообщения: посетитель сам нажимает «Отправить» в Telegram. Поддержка параметра text зависит от клиента; адрес всегда указывает на конкретный username.

## Публикация в существующий репозиторий

Репозиторий: `anufrii2020-sudo/Nikolay-Card`. Адрес сохраняется: https://anufrii2020-sudo.github.io/Nikolay-Card/. Имя репозитория и настройки Pages менять не нужно.

Архив `nikolai-card.zip` содержит готовые файлы с папкой assets. В `nikolai-iphone.zip` они находятся внутри папки nikolai-update; загружать нужно её содержимое, сохраняя структуру assets.

С iPhone:

1. Распакуйте свежий архив в приложении «Файлы».
2. Если папки assets в репозитории ещё нет, создайте файл `assets/.gitkeep` через Add file → Create new file и зафиксируйте его.
3. Откройте https://github.com/anufrii2020-sudo/Nikolay-Card/upload/main/assets . Выберите шесть WebP-файлов из папки nikolai-update/assets и нажмите Commit changes.
4. Откройте https://github.com/anufrii2020-sudo/Nikolay-Card/upload/main . Загрузите index.html, style.css, **script.js**, truck.jpg, favicon.svg, README.md и .nojekyll (если скрыт на iPhone, его можно пропустить). Нажмите Commit changes.
5. Дождитесь успешной публикации в Actions, затем обновите сайт. Для исключения старого кэша можно открыть адрес в частной вкладке Safari.

Для отправки изменений требуется авторизация GitHub с правом Contents: Read and write для этого репозитория. Чтение доступно, но создание ветки и git push при подготовке этой версии были отклонены с HTTP 403. Готовая локальная версия ожидает отправки.

## Проверка

Полный отчёт и скриншоты находятся в review/final-fixes/ и в nikolai-review.zip. Автоматически проверены четыре href и клика, декодирование точных сообщений, отсутствие механизмов выбора получателя, ссылки без JavaScript, прозрачность и целостность иконок, высота карточек 66 px, две строки нового текста топлива и отсутствие горизонтального переполнения на мобильных ширинах 320, 390, 393, 402 и 430 px. Дополнительно проверена настольная ширина 1440 px.

Навигация при кликах проверена через локальную подмену ответа — настоящий Telegram не запускался. Реальная проверка на физическом iPhone в Safari и встроенном браузере Telegram с другим Telegram-аккаунтом не проведена. Её нужно выполнить после публикации: нажать каждую из четырёх ссылок, убедиться в открытии чата @Nikolai_Makes_Sense и наличии правильного черновика, ничего не отправляя. Если черновик не поддерживается клиентом, проверить хотя бы правильный чат. Проверка из самого аккаунта Николая не подтверждает переход к другому пользователю: Telegram может показывать собственный чат «Избранное».
